# 听书版

这一版专门用来“听”：去掉了注释、来源链接、表格和图，正文改写成短句口语，适合手机朗读软件或真人朗读。

- 完整一本：`中国政治是怎么运转的-听书版.txt`（朗读软件首选）、`.docx`、`.md`
- 分章：本目录下的各章 Markdown
- `底稿/`：由 `制作/make-audio-base.py` 从书稿机械去注释得到，是改写的依据

现实情况以2026年9月29日为准，少数地方补到2026年11月26日。听书版不单独作为事实依据；与带注释的源稿有出入时，以`书稿/`为准。人物索引、延伸阅读、新闻阅读记录表和版本说明没有收入听书版。

重建顺序：修改 `书稿/` → `python 制作/make-audio-base.py` → 改写有变化的章节 → `python 制作/check-audio.py` → `python 制作/export-audio.py`。
