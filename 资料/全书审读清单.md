# 全书逐章审读清单

每章初稿完成后由主笔填写，不以子 Agent 自查代替统稿。

## 1. 叙事与章节边界

- 开头是否由人物和真实事件产生问题，而不是先下定义？
- 2—4名核心人物是否各有作用，有无可删的人名？
- 1—2条事件链是否承担制度解释，有无拼贴新闻？
- 是否重复前文；若深化旧概念，新增层次是什么？
- 结尾应用题是否检验制度与证据边界，而非背人名？

## 2. 事实与时间

- 人物现任身份是否由接近核验日的资料支持？
- 报道日、事件日、文件通过日、施行日是否分开？
- 历史人物是否使用当时职务，未以现任身份倒写？
- 是否把会议要求、计划目标或政策出台写成已经实现？
- 动态网页是否与有日期的公告或报道交叉核对？

## 3. 制度与证据

- 党内法规、法律、行政法规、政策文件和新闻报道是否区分？
- 现行文本是否确为当前版本，旧文重新上传是否被误认成修订？
- 正文概括是否超出脚注材料能够支持的范围？
- 是否从出席、缺席、排名、主持或报道篇幅推断内幕？
- 不知道的地方是否明确保留，而非用顺畅叙事填空？

## 4. 可读性

- 每个新概念出现前，读者是否先知道为什么需要它？
- 一段是否只推进一个主要意思？
- 条文细节是否尽量移入脚注？
- 表格、图或时间线是否确实降低理解成本？
- 是否机械模仿第一章句式，或反复使用同一种悬念？

## 5. 文件检查

- 编辑卡、正文、资料记录齐全。
- 注释定义唯一，正文引用全部有定义，无未引用注释。
- 无TODO、待补、内部检索编号或虚构链接。
- 章节标题、版本号、核验日期和阅读入口一致。
- 图表标签、正文与注释中的机构名称一致。
