# 第五章编辑卡：国务院怎样处理日常行政

编制及核查日期：2026年9月29日；2026年9月30日按独立审读修订为v0.2。依据《写作基准.md》《全书规划.md》和第一、二章v0.2。正文以可核查的公开记录为界。

- **核心问题：** 一条“国务院常务会议审议通过”的新闻，距离可适用的政策和窗口办理还有多远？总理、副总理、国务委员、部委及其他机构各在哪一段发挥作用？
- **主角人物：** 李强（总理，主持2026年7月31日会议并于8月10日签署第844号国务院令）；丁薛祥（副总理，用于说明协助总理、分工负责，依据2026年9月8日国务院专题学习报道核现任，不推断其参与本案具体协调）；吴政隆（国务委员兼国务院秘书长，用于说明秘书长和办公厅在日常运转中的位置，依据2026年3月全国人大报道及9月8日国务院专题学习报道核验，不推断其经手本案）；倪虹（住房城乡建设部部长，用于说明组成部门的行业职责，依据2026年9月20日公开活动报道核现任，不指定其为本案未公开的起草人）。
- **开场现实事件：** 新华社2026年7月31日国务院常务会议报道，会议审议通过修改住房公积金管理条例的决定草案；国务院第844号令载明同日会议通过、8月10日总理签署、9月20日施行。会议新闻和正式法规相互核对。
- **要解释的制度：** 总理负责制与会议讨论重大问题同时成立；副总理、国务委员按分工协助，秘书长处理日常工作；国务院组成部门、直属机构、办事机构的性质不同；国务院办公厅组织会议与公文办理；行政法规从起草、协调、审查、审议、签署公布到部门与地方落实。国务院2026年度立法工作计划已经确认本案由住房城乡建设部承担起草任务；正文把这一已知分工与未公开的实际参与人员、会签名单和协调过程分开。
- **历史案例：** 《住房公积金管理条例》1999年公布，2002年、2019年修订，2026年第三次修订。只借同一部条例说明行政制度随住房消费和就业形态改变；2026年修订的具体程序适用2026年7月1日起施行的《行政法规制定程序条例》，不以其倒推1999年。
- **2026现实坐标：** 事实截止9月29日；7月31日会议、8月10日签署、8月18日新华社发布、9月14日赣州配套文件、9月20日同步施行分开记录。赣州是可观察的地方接续例子；不由此推定全国所有窗口都已按同一细则办理。
- **章末应用：** 重读7月31日新华社会议新闻，区分“听取汇报”“研究”“审议通过草案”“决定核准”的动词，并追问公积金草案何时成为行政法规、由谁签署、地方办理还须查什么；附参考解释及证据边界。

核心事件为住房公积金条例2026年修改及其赣州配套调整这一条执行链。第一章的国务院定位、第二章的党组会与政府常务会只作简短回指；不重写任命程序、地方党政关系，也不提前展开第十三章的完整政策生命周期。
