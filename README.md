# 中国政治是怎么运转的

从制度、人物与现实事件读懂当代中国。

这本书面向普通读者，通过真实人物和事件解释机构、任免、政策与监督程序。它不是考试教材，也不写无法确认的政坛内幕。全书包含导读、24章及六个附录，正文依据第一章v0.2的叙事方法统稿，重要事实及制度规定在章末注明来源。

本版现实资料截止日为 **2026年9月29日**；查证日期可以更晚，历史身份和制度版本仍按事件当时记录。AI协作起草、独立审读及统稿方式详见[附录F](书稿/附录F-版本与勘误说明.md)。
