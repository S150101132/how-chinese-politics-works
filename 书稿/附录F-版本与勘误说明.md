# 附录F　版本与勘误说明

本稿的现实事实截止日为2026年9月29日。写作与后续复核可以发生在这一天之后；注释中的访问日记录查证时间，不把之后发生的事件纳入此前的现实截面。

本书采用AI协作起草、分章核查、独立审读与主笔统稿的制作方式。来源检查和修订记录随书稿保存，供复查使用。AI协作不使任何来源自动可靠，也不能替代未公开的原始材料；正文所能确认的内容，仍须由具体注释支撑。

本书有导读、第1—24章及附录A—F；各章的初稿与修订号属于编辑记录，不是统一的出版版次。整书修订时，应一并检查人物身份、制度版本、交叉引用、图表与附录，不能只替换姓名。网页版或动态领导页后来发生变化，也不会自动改写历史事件当时的身份。第22章的2024年挂牌现场与2026年机构负责人、第24章的河南代理省长记录，均应保留各自的事件日期；未来新任免出现时，须另作有日期的更新。

若读者发现错误，建议同时提供所在章节、原句、问题类型和可核查来源。日期错误、身份错误、统计口径不同、文献题名不符与解释越出证据，是不同的勘误；修订应写清改了什么、依据是什么、影响哪些段落。不能只把旧句删去而不记录理由。

| 勘误记录项 | 应填写的内容 |
| --- | --- |
| 位置 | 章名、小节与可定位的原句 |
| 原表述与问题 | 原句说了什么，哪一步不准确或没有足够支持 |
| 核查材料 | 标题、发布机构、日期、网址、关键段落或页码 |
| 修订 | 新表述及其证据范围 |
| 影响范围 | 是否涉及其他章节、图表、附录或输出文件 |
| 版本日期 | 本次修改日与下一版现实事实截止日，分别记录 |

读到“公开资料不足”时，也可以提供新的可靠资料帮助补齐。补齐的是证据，不是用更流畅的故事替代空白。
