# 附录E　下一条新闻的阅读记录

挑一条你确实想弄明白的新闻，先写一个具体问题。只记录已经打开、实际看过的材料；读不到的页面，留在待查栏。表格可以复制使用，也可以只在纸上写三行：事实、出处、下一问。

| 记录项 | 你的笔记 |
| --- | --- |
| 我的问题 | 这条新闻中，究竟哪件事让我困惑？ |
| 原始消息 | 标题、发布者、网址、发布日期、实际阅读日期 |
| 实际读取状态 | 原页全文、目录、转载、附件或仅检索摘要，分别读到了哪一种？打不开的原页记在待查栏 |
| 人物与身份 | 谁在此事中以哪一项职务出现？身份属于哪个时点？ |
| 机构与动作 | 哪个机构研究、提请、通过、任命、调查或实施？保持原文动词 |
| 时间与版本 | 事件日、决定日、公布日、施行日分别是什么？用的是草案、通过文本还是修正文本？ |
| 配套材料 | 任免决定、法律、通知附件、预算附表或后续实施文件在哪里？ |
| 最短事实句 | 用一句话写出所读材料直接支持的结果 |
| 解释与来源 | 哪一部分来自报道、当事人评价、学术研究或自己的推理？ |
| 仍缺的证据 | 要回答原问题，还需要哪份材料？当前空白不能证明什么？ |
| 后来更新 | 新增日期、材料与事实；保留旧记录，再修正当前结论 |

填完后，再看自己的最短事实句。是否把主持人写成了决定机关？是否删掉“代理”“涉嫌”“草案”等改变状态的词？是否把发文写成全部落实，把数量写成效果，把履历重合写成私人关系？找到哪一处越界，就改哪一句，不必把整条新闻变成一篇长论文。

第24章的三个练习可以作为第一次填写的对照：会议消息与通过文本分开读，任免报道与正式决定分开记，通知正文与附件表格一起看。下一次，请换一条书里没有讲过的新闻。
